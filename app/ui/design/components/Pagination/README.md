A page stepper for lists that page rather than scroll (search results, admin tables). **Brand kit pattern — not in @my/ui yet.** Timelines use Feed instead.

**Consumer provides:** page count and current page (`aria-current="page"`).

- 36px buttons, 10px radius, `surface-raised` with a 1px `border`, 700 weight. The current page fills `accent-fill` with a charcoal number. Ends read 「← 前へ」 「次へ →」.
