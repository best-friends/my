# 機能要件（v0）

優先度は MoSCoW で表します（**M**ust / **S**hould / **C**ould / **W**on't in v0）。
各要件 ID（`FR-xxx`）は Issue や PR から参照してください。

| FR-118 | 投稿の自動削除: 利用者ごとに、公開から指定した日数（1〜3650 日）を過ぎた自分の投稿を 1 時間ごとのジョブで削除し、本人の削除と同じく連合先へ `Delete` を送る。例外として、ピン留め・自分のブックマーク・自分のお気に入り・メディア付き・投票付き・選んだ公開範囲・ブーストかお気に入りの数が閾値以上の投稿を残せる。ブーストは対象外。1 回のジョブで消すのは 1 人 100 件まで | S |

## モデレーション・運営

| ID | 要件 | 優先度 |
| --- | --- | --- |
| FR-701 | 通報: ローカルの利用者がアカウントと投稿（複数可）を、カテゴリ（`spam` / `legal` / `violation` / `other`）・引用するルール・コメント付きで通報できる。リモートからの `Flag` も受け付ける。通報者の身元は通報された人に見せない | M |
| FR-702 | ドメイン単位の処分（`limit` / `suspend` / `reject_media` / `reject_reports` / `force_sensitive`、期限付き可、解除可） | M |
| FR-703 | アカウントへの処分: 警告、投稿のセンシティブ化・削除、メディアの強制センシティブ、サイレンス（全投稿をフォロワー限定にし、公開の場に出さない）、投稿禁止、ログイン停止、凍結、BAN（削除と再登録防止を伴う）。BAN 以外は期限付きにでき、解除できる。BAN は、削除までの 30 日のあいだの異議申し立て（FR-707）を覆したときだけ取り消せる。複数の処分は重ねられる。本人に種類・理由・期限を通知する（[ADR-0020](../adr/0020-data-modeling-principles.md)） | M |
| FR-704 | 監査ログ: 処分・解除・通報の対応・登録審査・ロールの付与と剥奪・インスタンス設定とルールの変更・拒否リストの変更を、操作者・日時・対象・理由とともに記録し、管理画面と CLI で新しい順に引ける（[ADR-0037](../adr/0037-audit-log.md)） | M |
| FR-705 | インスタンス設定（名前・説明・ルール・規約・登録モード・既定言語）を管理画面から変更 | M |
| FR-706 | ドメインブロックリストのインポート・エクスポート（Mastodon の CSV 形式） | C |
| FR-707 | 処分への異議申し立て（本人が 1 つの処分に 1 回、期間は [ADR-0038](../adr/0038-moderation-personal-data-retention.md)。BAN はアカウントの削除までの 30 日のあいだ）と、その審査（維持 / 撤回。BAN を撤回すると削除を取り消す）。結果を本人に通知する | S |
| FR-708 | 交流の禁止（フォロー・お気に入り・絵文字リアクション・ブースト・返信の禁止）処分 | S |
| FR-709 | 通報の転送: リモートのアカウントへの通報は、通報者が選べばインスタンス Actor から相手のサーバーへ `Flag` として送る（通報者は明かさない） | S |
| FR-710 | 通報の対応: 担当の割り当て・内部メモ・解決（処分した / 処分しない）・再開。通報の画面から処分を出すと、その通報を処分済みとして解決できる | M |
| FR-711 | 通報者への結果の通知: ローカルの通報者に、通報が解決したことを通知する（処分の内容と対象への処分の理由は含めない） | S |
| FR-712 | モデレーターへの通知: 新しい通報と承認待ちの登録を、権限を持つ利用者にアプリ内で通知し、未対応の件数を管理画面に出す。メールでの通知は利用者が選べる | M |
| FR-713 | リモートのアカウントへの処分（`limit` / `suspend` / `force_sensitive`）と解除を、管理 API・CLI・管理画面から行う | M |
| FR-714 | アカウントの管理: アカウントを名前・ドメイン・メールアドレスで検索し、詳細（登録日・登録審査・メール確認・ロール・処分と通報の履歴・最近のログイン元 IP）を見る。同じ IP・メールアドレスのドメインのアカウントを引ける。IP とメールアドレスは `manage_accounts` を持つ人にだけ見せる | M |
| FR-715 | 本人の処分の確認: 利用者は自分に効いている処分と過去の処分（種類・公開の理由・期限・違反とされた投稿）を設定の画面で確認でき、そこから異議を申し立てられる | M |
| FR-716 | 処分の連合への伝播: ローカルのアカウントの凍結・BAN・投稿の削除と、ドメインの凍結を、連合先に伝える（[ADR-0036](../adr/0036-moderation-federation-propagation.md)） | M |
| FR-717 | ドメインの凍結で切れたフォロー関係を記録し、影響を受けたローカルの利用者に件数を通知する | S |
| FR-718 | 処分したドメインの公開: インスタンスの情報ページと API で、処分したドメインの一覧（種類・公開コメント）を公開するか選べる。公開するときは一部を伏せ字にできる（`obfuscate`） | S |
| FR-719 | 登録の拒否リスト: メールアドレスのドメインと IP の範囲（CIDR）による登録の拒否・承認制への切り替え。期限付きにでき、BAN から作れる | S |
| FR-720 | ロールの付与と剥奪を管理 API・CLI・管理画面から、ロールの作成・変更・削除を管理 API・管理画面から行う（`manage_roles`）。自分より `position` の高いロールは扱えず、自分が持たない権限は付け外しできない。組み込みの `admin` は変えられず、`admin` と `moderator` は削除できない | S |
| FR-721 | 登録の審査（承認制の承認・却下）を管理画面から行う | M |
| FR-722 | サーバー単位の webhook: `manage_webhooks` を持つ人が、通報・登録の申請・アカウントの作成とプロフィールの変更・処分・異議・ドメインの処分・ローカルの公開投稿・カスタム絵文字の管理操作のイベントを、署名付き（Standard Webhooks）で外部の URL へ送る宛先を管理 API と管理画面から設定できる。失敗は再送し、配送の履歴を見られ、失敗が続く宛先は自動で無効になる（[ADR-0060](../adr/0060-instance-webhooks.md)） | S |
| FR-724 | 連合リレーの管理: `manage_settings` を持つ人がリレーを方式と URL で登録して参加・脱退し、状態（承認待ち・参加中・拒否・脱退）と受信の有無を管理 API・CLI・管理画面で扱う。操作は監査ログに残す（[ADR-0061](../adr/0061-federation-relays.md) ） | S |
| FR-725 | 検索と AI の拒否の表明（サーバー）: 検索エンジンの索引と AI の学習・利用の許否と、新規アカウントの `indexable` の既定をインスタンス設定で選び（未設定ならいずれも拒否の側）、`/robots.txt`・ページの meta と `X-Robots-Tag`・`/.well-known/tdmrep.json` で表明する。許否とその法的な位置づけ（著作権法 30 条の 4、EU DSM 指令 4 条）をサーバーの情報ページに出す。脆弱性の連絡先を設定すると `/.well-known/security.txt` を返す（[ADR-0057](../adr/0057-crawler-opt-out.md)） | S |
