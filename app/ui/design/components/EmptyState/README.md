What a list, a timeline or a search shows when it has nothing to show. **@my/ui:** `EmptyState` — `app/ui/src/EmptyState.tsx`.

**Consumer provides:** `heading` (「まだ投稿がありません」), `headingLevel` (one below the region's heading; 2 by default), `description`, a decorative `illustration` (an @my/ui icon), and an `action` (a Button or Link).

- Centered, 40px vertical padding. The illustration sits in an 88px `cream` tile (`radius-lg`) in `accent`.
- Heading in the serif voice: Georgia 22px/500. Description 14px `fg-muted`, max 60ch. Actions 8px apart.
- Say what the reader can do next, gently.
